## Multi-profile boundary

Both projects still bind the native HTTP service to a single configured port. The
reviewed fork resolves collisions by taking the port away from the previous native
host; it does not multiplex multiple Chrome profiles. JustBrowse deliberately does
not import that behavior because silently disconnecting the first profile would
violate session isolation. True simultaneous profile support needs an explicit broker
that registers multiple native-host connections and routes each MCP session to a
selected profile.
